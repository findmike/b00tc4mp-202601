# BASH

Common commands in BASH terminal

## pwd

Shows the path to the current working directory.

```bash
pwd
C:\Users\Mike\workspace\b00tc4mp-202601
```
## ls

Lists the files and folders in the current path.

```bash
Directorio: C:\Users\Mike\workspace\b00tc4mp-202601

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        11/02/2026     11:42                staff
-a----        06/02/2026     17:36           2291 .gitignore
-a----        06/02/2026     17:39             36 README.md
```
## mkdir

Used to create new folders in the current path.

```bash
mkdir playground
```
## cd

To change/navigate between your folders. 

```bash
cd music
```

## code workspace/"repo-url"

Used to open in Visual Studio Code your project folder from Git.

```bash
code workspace/b00tc4mp-202601
```
